1. Computer Hardware

Hardware is the physical part of a computer.

CPU

The CPU processes instructions and data.

RAM

RAM is temporary computer memory.

Motherboard

The motherboard connects the main components.

Keyboard

A keyboard is used to type information.

Monitor

A monitor displays information and images.

Storage

Storage saves files and programs.

2. Software

Software is made of programs and instructions.

Operating System

It manages the computer and its resources.

Application

A program used to perform a specific task.

File

A file contains digital information.

Folder

A folder is used to organize files.

Driver

A driver helps software communicate with hardware.

Kernel

The kernel is an important part of an operating system.

3. Networks and Internet

A network connects computers and other devices.

WordDefinition
NetworkA group of connected devices.
RouterA device that connects networks.
ServerA computer that provides services or resources.
Wi-FiWireless network connection.
IP AddressAn address that identifies a device on a network.
BandwidthThe amount of data that can be transferred.

4. Cybersecurity

Cybersecurity helps protect computers, networks and information.

Password

Secret information used to access an account.

Phishing

A fake message designed to obtain information.

Malware

Malicious software that can harm a system.

Firewall

It controls network traffic.

Encryption

It protects information by changing it into a coded form.

Backup

A copy of important information.

Reading Activity

A Day in an IT Lab

Maria is a student in an IT laboratory. She starts the computer and checks the operating system. Then she connects to the school network using Wi-Fi. She saves her work on the server. Before leaving the lab, she makes a backup of her important files.

Questions

  1. Where does Maria study?
  2. What does she check?
  3. How does she connect to the network?
  4. Where does she save her work?
  5. What does she do before leaving?
